③ 管理員指令一覽

指令功能觸發動作
/ok [編號] 確認預約日期 狀態 pending → awaiting_payment，發匯款 QR Code 給客人
/no [編號] 婉拒預約 刪除預約，通知客人可重新選擇
/paid [編號] 確認收款完成 建立 Google Calendar 事件，發確認 Flex 卡片，保留 done 紀錄 30 天
/change [編號] YYYY-MM-DD HH:MM 改期 更新 KV 時間；若已付款則同步更新 Google Calendar；發改期卡片給客人
/list 列出所有進行中預約 顯示 pending / awaiting_payment / payment_reported 全部
/clear 清除所有進行中預約 一次刪除佇列中所有預約
/off / /on Bot 開關 關閉時客人傳訊會收到「老師在線上」提示（每次關閉期間每人只提示一次）
/myid 查詢自己的 LINE User ID 回覆 User ID（用於設定 ADMIN_LINE_USER_ID 環境變數）
